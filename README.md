# Teste de Lógica — C#

Projeto desenvolvido em **C#** para resolução de exercícios de lógica de programação.

## Exercícios

* `questao1` até `questao6`
* `bonus`

## Tecnologias

* C#
* .NET

## Como executar

Escolha a questão:

```bash
cd questao1
dotnet run
```

Para executar outra:

```bash
cd ..
cd questao2
dotnet run
```
